# Telegram Bot — SHADDAI

Telegram bot for the SHADDAI ecosystem: signals, PnL, news, wallets, trading.

## Files
- `telegram-bot.js` — main bot entry
- `telegram-core.js` — core handlers
- `telegram-signals.js` — signal delivery
- `telegram-news.js` — news feed
- `telegram-pnl.js` — PnL tracking
- `telegram-wallets.js` — wallet management
- `telegram-routes.js` — HTTP routes
- `TELEGRAM.html` — web dashboard

## Setup
Set env vars (BOT_TOKEN, etc.) — no secrets committed.
Run with Node.
